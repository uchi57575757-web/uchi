# UCHI OFFICIAL — 우치 팬페이지

승인된 메인 시안(1200×865)을 그대로 옮기고, 프로필·공지·업보·옷장과 관리자를 붙인 정적 사이트입니다.
데이터는 Supabase에 저장되고, 화면에 보이는 값은 전부 관리자에서 고칠 수 있습니다.

```
index.html          메인
style.css           전 페이지 공통 스타일 · 팔레트
site.js             공통 배선 (폭 맞춤 · 다크 · 문의 모달 · 머리글)
supabase.js         DB 연결 — 상단 두 줄만 교체
fx.js               연출 (떠다니는 하트 · 클릭 반창고 · 페이지 전환)
supabase_setup.sql  표 생성 + 접근 권한
assets/             히어로 누끼 png · 왼쪽 사진 2장 · 배너 장식 · 프사 움짤 2개 · 배너 제목 글꼴
minigame/index.html 미니게임 (돌림판)
profile/index.html  프로필
notice/index.html   공지
work/index.html     업보
dress/index.html    옷장
admin/index.html    관리자
```

## 1. Supabase

1. supabase.com → New project → 이름은 아무거나. 리전은 Northeast Asia (Seoul).
2. **Authentication → Users → Add user** 로 관리자 계정을 먼저 만듭니다. **Auto Confirm User 를 켜세요.**
3. **SQL Editor** 에 `supabase_setup.sql` 전체를 붙여넣고 Run.
   순서를 반대로 하면 쓰기 권한이 잠겨 본인도 관리자에서 저장할 수 없습니다.
4. `supabase.js` 의 프로젝트 주소와 anon 키는 **이미 채워져 있습니다** (`wxriequozugedpzayfjx`).
   다른 프로젝트로 옮길 때만 맨 위 두 줄을 교체하면 됩니다.

```js
const SUPABASE_URL  = 'https://프로젝트ID.supabase.co';
const SUPABASE_ANON = 'anon public 키';
```

anon 키는 원래 공개용이라 소스에 들어 있어도 됩니다. 실제 권한은 SQL 의 RLS 가 나눕니다 —
읽기는 누구나, 쓰기는 로그인한 관리자만.

관리자 비밀번호는 코드 어디에도 들어 있지 않습니다. 계정 추가·비밀번호 변경·관리자 제외는
전부 Supabase → Authentication → Users 에서 처리합니다.

## 2. GitHub → Cloudflare Pages

1. 이 폴더를 그대로 GitHub 저장소에 올립니다. `fx.js` · `site.js` · `style.css` 는 루트에 있어야 합니다.
2. Cloudflare Pages → Connect to Git → 저장소 선택 → 빌드 설정은 비웁니다(Framework = None) → Deploy.
3. 파일을 고친 뒤에는 덮어쓰기 → Commit → 1~2분 → 브라우저에서 **Ctrl+Shift+R**.

## 3. SOOP 게시글에 넣기

게시글에는 **페이지 주소를 그대로** 넣습니다. 래퍼 주소나 중첩 iframe 은 숲 앱에서 무한 새로고침을 일으킵니다.

```html
<iframe height="820" scrolling="no" src="배포주소" style="width:100%;border:0;display:block;"></iframe>
```

전 페이지가 1200px 고정 디자인이고, 화면이 좁으면 그 배치를 그대로 축소해서 보여줍니다.
그래서 폰에서도 PC 배치가 나오고, 세로 높이는 폭에 비례합니다.

메인 페이지 기준 폭별 높이 (데이터가 없을 때):

| iframe 폭 | 높이 |
|---|---|
| 1100px | 793 |
| 1000px | 721 |
| 820px | 592 |
| 600px | 433 |

한 값만 적어야 하면 **높은 쪽**을 씁니다. 여백이 남는 편이 게시글 안에 스크롤이 또 생기는 것보다 낫습니다.
프로필·공지·업보·옷장은 등록한 내용만큼 길어지므로, 그 페이지를 임베드할 때는 실제 화면을 보고 높이를 정하세요.

게시글 안(iframe)에서는 화면 왼쪽 위에 **전체 화면 ↗** 버튼이 나옵니다. 숲 앱에서 크게 보고 싶을 때 씁니다.

## 4. 관리자

`배포주소/admin/` 으로 들어가서 1번에서 만든 이메일·비밀번호로 로그인합니다.

| 탭 | 넣는 것 |
|---|---|
| 🏠 메인 | 히어로 누끼·상단 프사·왼쪽 사진 2장, 메인 문구, 이번주 일정 |
| 🎀 프로필 | 프사, 프로필 정보, 키워드, 한마디·하고픈 말, 좋아/싫어, 해본 게임, 능력치·목표, TMI, 링크, 다시보기 |
| 📢 공지 | 공지 등록·삭제 |
| 😈 업보 | 시청자, 업보 종류, 시청자별 횟수 |
| 👗 옷장 | 헤어·의상·렌즈 등록. "새 옷으로 올리기"를 체크하면 포스터로 나옵니다 |
| 🎲 미니게임 | 돌림판 항목 (한 줄에 하나) |
| ✏️ 문구 | 각 페이지 맨 위 머리글 |
| 🎨 테마 | 팔레트 7색(프리셋·대비 진단), 글자 크기 4단 배율 |
| 📮 문의 | 사이트 문의 버튼으로 들어온 내용 |

- 각 카드의 **나오는 곳** 한 줄이 그 값이 어느 화면에 반영되는지 알려 줍니다.
- 값을 비우면 페이지에 적힌 기본 문구가 그대로 나옵니다. 능력치·목표·NOW·TMI 는 비면 카드 자체가 숨겨집니다.
- 상단 **백업** 으로 모든 입력값을 `.json` 으로 내려받고, **복원** 으로 되돌릴 수 있습니다.
- 저장하지 않고 나가려 하면 확인 창이 뜹니다.

## 5. 이번주 일정

관리자 🏠메인 탭 → **이번주 일정** 에서 요일마다 체크와 시간을 넣습니다.
한 곳만 고치면 **메인 화면의 일정표 카드와 프로필 WEEK 카드 두 곳**이 같이 바뀝니다.

체크를 풀면 그 요일은 휴방으로 표시되고 시간 칸은 잠깁니다.

## 6. 다크 모드

오른쪽 위 해/달 버튼으로 켜고 끕니다. 선택은 `localStorage` 에 저장되어 페이지를 옮겨도 유지됩니다.

배너 안의 캐릭터는 **배경을 지운 투명 PNG**(`assets/hero-char.png`)라서 라이트·다크 어디서든
그대로 쓰입니다. 다크 모드에서는 배너 색만 진한 자주색으로 바뀝니다.

> 히어로 이미지를 바꿀 때는 **반드시 배경을 지운 PNG**로 넣으세요. 배경이 있는 사진을 넣으면
> 배너 밖으로 나온 머리·손 부분에 사진의 네모난 배경이 그대로 비칩니다.

## 7. 이미지 넣는 법

이미지는 파일을 올리지 않고 **주소(URL)** 로 넣습니다.

1. SOOP 비공개 게시판에 이미지를 올립니다.
2. 올라간 이미지에서 **우클릭 → 이미지 주소 복사** (글 주소가 아니라 `https://stimg.sooplive.com/...` 로 시작하는 주소).
3. 관리자의 이미지 칸에 붙여넣습니다. 칸 아래에 미리보기가 뜨면 제대로 들어간 것입니다.

- 옷장: 세로 3:4 (예 900×1200)
- 메인 왼쪽 사진 2장: 세로 3:4
- 메인 히어로: 배경 없는 투명 PNG. 가로 838×787 기준
- 상단 왼쪽 프사: 정사각. 움짤(.gif)도 됩니다
- 프로필 프사: 정사각. 움짤(.gif)도 됩니다

`assets/` 의 기본 이미지를 바꾸려면 같은 파일 이름으로 덮어쓰고 다시 배포하면 됩니다.
관리자에서 주소를 넣으면 그쪽이 우선합니다.

## 7-1. 글꼴

| 쓰는 곳 | 글꼴 | 어디서 오나 |
|---|---|---|
| 배너 큰 제목 (`안녕!우치!`) | 강원교육튼튼 ExtraBold | `assets/uchi-display.woff2` (레포 동봉) |
| 그 밖의 모든 글자 | Pretendard | jsDelivr CDN (`index.html` 의 `<link>`) |

배너 제목 글꼴은 우치가 준 PSD 시안에 쓰인 것과 같은 글꼴입니다. 강원도교육청이 배포하는
무료 글꼴로 상업적 이용·웹폰트 임베딩이 허용됩니다. 쓰는 글자만 남기고 잘라내서
390KB → 118KB(woff2) 로 줄여 레포에 넣었습니다 — CDN 이 막혀도 제목은 그대로 나옵니다.

글꼴을 바꾸려면 `style.css` 맨 위 `@font-face` 의 파일과 `--font-display` 값을 함께 고칩니다.
`--font-display` 를 다른 제목(`.section-title-row h2` 등)에도 걸면 페이지 전체 제목이 이 글꼴이 됩니다.
